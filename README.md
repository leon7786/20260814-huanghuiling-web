## 🌐 网页版交互体验 (Web Application)

本项目包含一套纯原生、高性能的交互式 Web 规划系统：

* **应用首页**：`index.html`（可直接在浏览器打开或通过本地 HTTP 服务访问）
* **核心功能**：
  1. **路线多维度筛选**：可按天数（3-5天 / 6-8天 / 10+天）、主题（海岛风光 / 饕餮美食 / 山水民族 / 史诗进藏）快速过滤。
  2. **每日动态 Timeline 展开**：精细展示每天的公里数、行驶时长、打卡景点与正宗美食。
  3. **自驾预算在线计算器**：自动根据行驶里程、油耗/电耗、过路费、酒店星级、餐标，实时计算单车总预算与人均消费。
  4. **行程检查与清单导出**：内置长途/高海拔/海岛自驾专属 Checklist。

## 🚘 珠海出发通用自驾指南

* 详见文档：[珠海出发自驾准备与避坑指南](docs/zhuhai-self-driving-guide.md)
* **避坑要点**：
  * 前往粤东潮汕方向建议通过深中通道或港珠澳连接线错峰出行；
  * 琼州海峡过海切记在“徐闻港”微信公众号提前预订船票；
  * 进入云南/西藏高海拔地区建议阶梯式适应海拔并随车携带便携式氧气瓶。
