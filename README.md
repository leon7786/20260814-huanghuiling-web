## 🌐 网页版交互体验 (Web Application)

* **网页运行地址**：[https://leon7786.github.io/20260814-huanghuiling-web/](https://leon7786.github.io/20260814-huanghuiling-web/)
* **核心功能**：
  1. **路线多维度筛选与检索**：支持关键词搜索（如“珠峰”、“阿里”、“南澳大桥”）与按天数（含30天超长途）、主题快速过滤。
  2. **每日动态 Timeline 展开**：查看每天的公里数、行驶时长、打卡景点与地道美食。
  3. **自驾预算在线计算器**：自动根据行驶里程、油耗/电耗、过路费、酒店星级、餐标，实时计算单车总预算与人均消费。
  4. **行程检查与清单导出**：内置长途/高海拔/海岛自驾专属 Checklist。
