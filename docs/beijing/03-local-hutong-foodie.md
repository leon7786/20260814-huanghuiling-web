# 路线三：【老北京人私藏】胡同烟火与牛街美食 5天4晚

> **热度指数**：北京本地人极力推荐 / 深度避坑饕餮线  
> **本地人点评**：“这才是老北京人平时带亲戚朋友逛的路线！吃牛街正宗清真、听智化寺宫廷古乐、看国子监古柏，没有大团拥挤。”

---

## 每日详细行程

### **Day 1：胡同老街 · 东交民巷 ➔ 前门大栅栏 ➔ 中山公园**
* **上午**：漫步【东交民巷】（北京最长的西洋建筑老街，拍照极其安静优雅）。
* **下午**：漫步【中山公园】观赏社稷坛五色土与古柏林，逛前门大栅栏与三市口老字号。
* **晚上**：享用【南门涮肉】（日坛店/天坛店，传统鲜切羊肉搭配秘制麻酱）。

### **Day 2：古刹祈福与学府古树 · 雍和宫 ➔ 国子监/孔庙 ➔ 五道营胡同**
* **09:00** 朝圣【雍和宫】（藏传佛教名刹，领免费香祈福，观赏18米整木白檀大佛）。
* **11:30** 游览【国子监与孔庙】，漫步元明清最高学府与700年古柏树林。
* **14:00** 漫步【五道营胡同】，这里没有南锣鼓巷的喧嚣，充满独立咖啡馆、手作小店与老北京院落生活。
* **18:00** 享用【四季民福烤鸭】或京味家常菜。

### **Day 3：饕餮盛宴 · 智化寺明代古乐 ➔ 琉璃厂 ➔ 牛街正宗清真美食**
* **10:00** 游览【智化寺】，现场聆听国家非遗【智化寺京音乐】（明代宫廷音乐活化石，至今传承二十八代）。
* **13:00** 漫步【琉璃厂古玩字画街】，感受文房四宝古韵。
* **16:30** 直奔老北京美食圣地【牛街】！
  * **必吃榜**：聚宝源（铜锅涮肉）、奶酪魏（宫廷奶酪）、吐鲁番餐厅（烤羊肉串）、白记年糕（驴打滚/艾窝窝）、宝记豆汁。

### **Day 4：水乡胡同 · 北海公园荡双桨 ➔ 什刹海西海湿地 ➔ 护国寺**
* **09:00** 游览【北海公园】，租小船荡舟湖上，看白塔与九龙壁。
* **13:30** 漫步【西海湿地公园】（什刹海最清幽的原生态水域），沿着木栈道看水鸟与荷花。
* **17:00** 逛【护国寺胡同】，品尝护国寺小吃店传统小吃。

### **Day 5：天坛公园看大爷晨练 ➔ 返程**
* **08:30** 漫步【天坛公园】，看老北京大爷大妈打太极拳、踢毽子、拉二胡，体验地道京味烟火气后返程。
