# 路线五：历史古迹与老北京胡同原汁原味 5日游

> **定位**：真古迹 + 明清胡同水系 + 古佛寺古壁画 + 传统京味文化  
> **核心遗迹景点**：故宫博物院、前门/正阳门、雍和宫、国子监古树群、智化寺古乐、石景山法海寺明壁画

---

## 每日详细行程

### **Day 1：明清帝都核心 · 天安门 ➔ 前门正阳门 ➔ 故宫博物院**
* **上午**：漫步天安门广场与正阳门古城楼，游览【故宫博物院】，深入太和殿、文华殿与御花园。
* **下午**：登上【景山公园】万春亭，俯瞰紫禁城全景，随后漫步【东交民巷】古建筑群。
* **美食推荐**：四季民福烤鸭、老北京炸酱面。

### **Day 2：古树古刹与儒释道文化 · 雍和宫 ➔ 国子监/孔庙 ➔ 智化寺**
* **上午**：朝圣【雍和宫】（北京最大的藏传佛教寺院，观赏18米高整棵白檀木雕刻的迈达拉弥勒大佛）。
* **下午**：漫步【国子监与孔庙】，游览700年历史的元明清最高学府与百年古柏树林；打卡【智化寺】，聆听国家非遗“智化寺京音乐”（明代宫廷音乐活化石）。
* **美食推荐**：雍和宫素斋、护国寺小吃。

### **Day 3：真正民俗胡同水系 · 南锣鼓巷老胡同 ➔ 什刹海 ➔ 烟袋斜街**
* **上午**：深入【五道营胡同】与【菊儿胡同/雨儿胡同】，感受老北京院落生活气息（避开商业主街）。
* **下午**：沿【什刹海】与【烟袋斜街】徒步，观赏沿岸柳树与宋庆龄故居庭院水系。
* **美食推荐**：爆肚宛、老北京豆汁儿、铜锅涮肉。

### **Day 4：明代壁画巅峰 · 石景山【法海寺】➔ 翠微山**
* **上午**：前往石景山区【法海寺】，观赏距今570余年的明代宫廷壁画（与敦煌壁画齐名的中国壁画艺术巅峰，至今沥粉贴金色彩鲜艳）。
* **下午**：游览【八大处公园/翠微山】，漫步在山林古刹与泉水之间。
* **美食推荐**：石景山京味小吃、烤肉。

### **Day 5：天坛古柏树群 ➔ 返程**
* **上午**：游览【天坛公园】，漫步于回音壁与百年古柏林中，感受古代祭天礼仪人文哲学后顺利返程。
