# 路线三：太行京西峡谷与高山草甸生态探秘 5日游

> **定位**：高山草甸 + 喀斯特天坑大溶洞 + 拒马河峡谷 + 明清古村  
> **核心自然景点**：门头沟百花山高山草甸、灵山自然保护区、房山十渡拒马河峡谷、石花洞地下溶洞、爨底下古村

---

## 每日详细行程

### **Day 1：北京 ➔ 门头沟【爨底下明清古村】**
* **上午**：从市区驾车前往门头沟太行山脉余脉（约 2 小时）。
* **下午**：游览【爨底下村】（保存最完整的明清四合院古村落，依山而建，错落有致），登上对面观景台俯瞰古村“金元宝”地貌格局。
* **美食推荐**：爨底下压饸饹面、炸槐花、山珍炒野笋。

### **Day 2：门头沟【百花山高山草甸自然保护区】**
* **全天**：游览【百花山自然保护区】（海拔2000米，华北植物宝库），徒步木栈道穿越高山云海与千亩野花高山草甸，感受凉爽天然氧吧。
* **美食推荐**：高山烤全羊、柴鸡蛋。

### **Day 3：门头沟 ➔ 房山【石花洞地下大溶洞】**
* **上午**：驱车前往房山区【石花洞国家地质公园】（中国四大名洞之一）。
* **下午**：游览7层地下溶洞系统（开放1-4层），观赏天然形成的石花、石柱、石竹与地下暗河奇观。
* **美食推荐**：房山房山饸饹面、磨盘柿干。

### **Day 4：房山【十渡国家地质公园】➔ 拒马河峡谷**
* **全天**：游览【十渡国家地质公园】，感受北方罕见的喀斯特峰林峡谷地貌。沿着【拒马河峡谷】自驾，体验清凉峡谷竹筏或漂流。
* **美食推荐**：十渡拒马河虹鳟鱼、烤山羊腿。

### **Day 5：圣莲山自然风景区 ➔ 返程**
* **上午**：游览被称为“京西小武当”的【圣莲山风景区】，观赏高耸入云的峰林与天然莲花山谷地貌，下午返程。
