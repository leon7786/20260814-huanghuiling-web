# 路线二：皇家园林与自然山水人文深游 5日游

> **定位**：山水理水艺术 + 百年古树奇石 + 皇家山水园林  
> **核心自然与园林景点**：颐和园昆明湖、圆明园遗址公园、景山公园、天坛古树群、北海公园/什刹海水系

---

## 每日详细行程

### **Day 1：皇家水系精华 · 颐和园 ➔ 圆明园遗址**
* **上午**：游览世界文化遗产【颐和园】，漫步万寿山、昆明湖十七孔桥、西堤六桥（仿杭州西湖长堤），感受中国古典园林山水造景巅峰。
* **下午**：游览【圆明园遗址公园】，漫步福海湖畔、绮春园与长春园西洋楼遗址，体验水域辽阔与沧桑历史。
* **美食推荐**：宫廷豌豆黄、炸酱面、烤鸭。

### **Day 2：古都中轴与山水俯瞰 · 故宫博物院 ➔ 景山公园看全景**
* **上午**：朝圣世界最大木结构建筑群【故宫博物院】（紫禁城），漫步太和殿、乾清宫、御花园。
* **下午**：登【景山公园】万春亭（北京中轴线最高点），360度俯瞰紫禁城金碧辉煌的全景与北海公园水系。
* **美食推荐**：老北京铜锅涮肉、炙子烤肉。

### **Day 3：古树群与祈天圣地 · 天坛公园 ➔ 陶然亭公园**
* **上午**：游览世界文化遗产【天坛公园】，观赏祈年殿、皇穹宇，漫步拥有数千株百年古柏树的天然森林氧吧公园。
* **下午**：游览【陶然亭公园】，观赏水系与名亭园林（如醉翁亭、兰亭等仿古名亭群）。
* **美食推荐**：南门涮肉、爆肚冯、豆汁焦圈。

### **Day 4：皇家水上长廊 · 北海公园 ➔ 什刹海（后海/前海水系）**
* **上午**：游览【北海公园】，“让我们荡起双桨”发源地，观赏白塔、九龙壁与琼华岛。
* **下午**：漫步【什刹海】（前海、后海、西海三块水域），沿着水岸观赏柳树依依，打卡银锭桥“银锭观山”远眺西山余脉。
* **美食推荐**：烤肉季芝麻酱烧饼、爆肚、护国寺小吃。

### **Day 5：中山公园与皇城水系 ➔ 顺利返程**
* **上午**：游览【中山公园】（社稷坛与五色土），漫步古柏林与海棠花海，顺着护城河水系散步后返程。
