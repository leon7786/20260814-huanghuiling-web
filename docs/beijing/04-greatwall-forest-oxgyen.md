# 路线四：长城森林与氧吧四季风光 5日游

> **定位**：长城雄关 + 原始森林红叶 + 怀柔湖光山色 + 塔林石刻  
> **核心自然景点**：慕田峪长城、喇叭沟门原始森林、怀柔雁栖湖、红螺山、昌平银山塔林

---

## 每日详细行程

### **Day 1：怀柔【慕田峪长城】（森林覆盖率96%）**
* **上午**：驾车前往怀柔【慕田峪长城】（英国泰晤士报评选为中国长城最美段）。
* **下午**：搭乘缆车登上长城，徒步正关台、英雄台与第20号敌楼，观赏蜿蜒在森林峰峦之上的长城巨龙。
* **美食推荐**：怀柔虹鳟鱼三吃、栗子焖肉。

### **Day 2：怀柔【喇叭沟门原始森林公园】**
* **全天**：驾车前往被称为“北京北极”的【喇叭沟门原始森林公园】，徒步白桦林保护区、南猴顶与枫叶谷，置身于千亩原始次生林中极目远眺。
* **美食推荐**：满族二八席、烤野兔。

### **Day 3：怀柔【红螺山风景区】➔ 雁栖湖**
* **上午**：游览【红螺山/红螺寺】，漫步紫竹林、松林步道与千亩古银杏林，登红螺山观景台远眺全景。
* **下午**：游览【雁栖湖】，沿着雁栖湖环湖步道徒步或骑行，观赏湖光山色与雄伟雁栖塔。
* **美食推荐**：雁栖湖小鱼小虾、怀柔板栗。

### **Day 4：怀柔 ➔ 昌平【银山塔林风景区】**
* **上午**：驱车驶往昌平区【银山塔林】（被称为“铁壁银山”）。
* **下午**：游览耸立于悬崖与松柏林间的法华禅寺辽代古塔群，漫步山林步道登顶俯瞰松涛阵阵。
* **美食推荐**：昌平十三陵王家梯子峪烙糕宴。

### **Day 5：奥林匹克森林公园 ➔ 返程**
* **上午**：游览市区最大的天然森林氧吧公园【奥林匹克森林公园】（南北园区），漫步露天湿地湖泊与仰山后返程。
