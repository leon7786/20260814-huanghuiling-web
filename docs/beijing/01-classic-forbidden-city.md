# 路线一：【知乎万赞爆款】帝都皇城中轴经典 5天4晚

> **热度指数**：知乎 10万+ 赞 / 携程高分首选  
> **本地人点评**：“首次来北京最合理的经典中轴线打卡，涵盖所有必去地标，行程顺畅不走回头路。”

---

## 每日详细行程

### **Day 1：初识京城 · 天安门 ➔ 故宫博物院 ➔ 景山公园看紫禁城落日**
* **08:30** 天安门广场合影，瞻仰毛主席纪念堂。
* **10:00** 从午门进入【故宫博物院】，走中轴线（太和殿、中和殿、保和殿 ➔ 乾清宫、交泰殿、坤宁宫 ➔ 御花园 ➔ 珍宝馆/钟表馆）。
* **16:00** 出神武门后登【景山公园】万春亭，360度俯瞰紫禁城金碧辉煌的落日全景。
* **18:30** 享用【四季民福烤鸭】（酥香嫩滑，搭配鸭皮沾白糖）。

### **Day 2：雄关壮丽 ➔ 奥林匹克公园看双辉夜景**
* **08:00** 搭乘高铁（北京北站/清河站 20分钟直达）前往【八达岭长城】（或选择森林覆盖率96%的【慕田峪长城】）。
* **14:30** 返回市区前往【奥林匹克公园】，打卡鸟巢（国家体育场）与水立方（国家游泳中心）外观。
* **18:30** 前往【簋街】享用麻辣小龙虾或【聚宝源】铜锅涮肉。

### **Day 3：皇家水乡 · 颐和园 ➔ 圆明园 ➔ 清华/北大打卡**
* **08:30** 游览【颐和园】（建议“东宫门进、北宫门出”），漫步长廊、佛香阁、昆明湖十七孔桥与西堤。
* **13:30** 游览【圆明园遗址公园】，打卡福海湖畔与西洋楼遗址（大水法）。
* **16:30** 前往清华大学/北京大学正门打卡合影。
* **18:30** 中关村享用美食。

### **Day 4：古树盛境 ➔ 恭王府 ➔ 什刹海胡同水系**
* **08:30** 游览【天坛公园】，打卡祈年殿、皇穹宇，漫步百年古柏森林。
* **12:00** 游览【恭王府】（“一座恭王府，半部清代史”），打卡康熙御笔福字碑。
* **15:00** 漫步【什刹海】（前海、后海、烟袋斜街），打卡银锭观山落日，逛【南锣鼓巷】。
* **18:30** 享用【烤肉季】芝麻酱烧饼与烤羊肉。

### **Day 5：文化大满贯 · 国家博物馆 ➔ 前门大栅栏 ➔ 返程**
* **09:00** 朝圣【中国国家博物馆】（观赏古代中国展与复兴之路展）。
* **13:00** 逛【前门大栅栏】鲜鱼口小吃街，体验老北京铜人与老字号。
* **16:00** 顺利前往机场/高铁站返程。
