# 路线五：【京郊长城度假】古北水镇与司马台夜景 5天4晚

> **热度指数**：休闲度假高赞推荐 / 摄影夜景必选  
> **本地人点评**：“长城脚下的水乡绝美夜景！孔明灯无人机秀、司马台长城晨曦与雁栖湖，适合带家人松弛度假。”

---

## 每日详细行程

### **Day 1：抵京 ➔ 密云【古北水镇】夜游无人机秀**
* **下午**：抵达北京后租车/乘专线巴士前往密云区【古北水镇】（约 1.5 小时）。
* **晚上**：漫步古北水镇水乡石板路，观赏【望京楼音乐水舞秀】与数百架【无人机孔明灯夜空秀】，入住水镇特色客栈/温泉酒店。

### **Day 2：司马台长城缆车 ➔ 怀柔【雁栖湖】**
* **上午**：搭乘缆车登上【司马台长城】，俯瞰清晨长城在晨雾中的陡峭雄姿。
* **下午**：驱车驶往怀柔【雁栖湖】，游览APEC会址景观与环湖景观大步道。
* **晚上**：享用怀柔特色【虹鳟鱼三吃】（刺身、盐烤、红烧）。

### **Day 3：怀柔【慕田峪长城】滑道 ➔ 红螺山**
* **上午**：游览【慕田峪长城】，体验极具特色的滑道高速下山。
* **下午**：游览【红螺山/红螺寺】，漫步古竹林与古松林。

### **Day 4：延庆【百里山水画廊】自驾 ➔ 龙庆峡 / 野鸭湖**
* **上午**：驾车行驶在延庆百里山水画廊自驾公路。
* **下午**：游览【龙庆峡】（被称为“北方小桂林”，乘船穿行于悬崖峭壁峡谷之间）或【野鸭湖湿地公园】。

### **Day 5：延庆【玉渡山】高山草甸 ➔ 市区返程**
* **上午**：游览【玉渡山自然风景区】，漫步高山草甸与忘忧湖，午后驶回市区机场/车站返程。
